README

Базовый серверный веб-шаблон на Django с регистрацией, сессионной авторизацией и профилем пользователя.

Важно: текущий проект не является Django REST Framework API и не использует JWT. Эта страница описывает фактическую реализацию репозитория.

Назначение и возможности

Шаблон содержит домашнюю страницу, HTML-формы регистрации и входа, стандартную модель пользователя Django, профиль с необязательным аватаром, SQLite и административную панель.

  • Регистрация с username, обязательным email и подтверждением пароля.
  • Сессионный вход и выход через Django auth.
  • Автоматическое создание Profiles после регистрации.
  • Наследуемые HTML-шаблоны и Bootstrap 5.3.8 через CDN.
  • Django 6.1.1 и локальная SQLite-база.

Установка и запуск

python -m venv venv
source venv/bin/activate          # Linux/macOS
# venv\Scripts\activate       # Windows
pip install -r req.txt
python manage.py migrate
python manage.py check
python manage.py runserver

Сайт будет доступен по адресу http://127.0.0.1:8000/. Админ-панель находится на /admin/.

python manage.py createsuperuser
python manage.py runserver 0.0.0.0:8010

Маршруты

МетодПутьНазначениеДоступ
GET/Домашняя страница, шаблон main/main.html.Все
GET, POST/sign-up/Регистрация пользователя через RegisterForm.Все
GET, POST/login/Стандартный LoginView Django.Все
GET, POST/login_/Дополнительный ручной обработчик входа.Все
GET/logout/Удаление текущей сессии.Авторизованные
GET/admin/Административная панель.Staff

Маршрут /login/ появляется из django.contrib.auth.urls. Маршрут /login_/ объявлен в mainapp/urls.py. Рекомендуется оставить один вариант входа.

Регистрация

Форма на POST /sign-up/ принимает поля username, email, password1 и password2. После успешной проверки создаётся User, создаётся связанный Profiles, затем пользователь автоматически входит и перенаправляется на главную страницу.

Форма использует CSRF-защиту. Проверки пароля выполняются стандартным UserCreationForm и настройками AUTH_PASSWORD_VALIDATORS.

Профиль и модели

Profiles
  id      BigAutoField
  user    OneToOneField(User, related_name="profile", on_delete=CASCADE)
  avatar  FileField(upload_to="avatars/", null=True)

Обратный доступ к профилю: request.user.profile. Поле аватара пока не подключено к HTML-форме, а настройки MEDIA_ROOT и MEDIA_URL отсутствуют.

Миграции и проверки

python manage.py makemigrations
python manage.py migrate
python manage.py showmigrations
python manage.py test
python manage.py shell

Миграция 0002 удаляет старые модели Staff, Users, StaffInfo и Sessions, добавляя актуальную модель Profiles.

Известные ограничения

  • В settings.py включён DEBUG = True, а ALLOWED_HOSTS разрешает все хосты.
  • SECRET_KEY хранится в исходном коде.
  • В навигации есть ссылки profile и my_sessions, но маршруты для них не определены.
  • Главная страница пока не содержит контента в блоке content.
  • Тесты и регистрация аватара ещё не реализованы.
  • Bootstrap загружается с CDN.

Production checklist

  • Вынести секреты в переменные окружения.
  • Отключить debug и ограничить allowed hosts.
  • Настроить HTTPS, secure cookies и CSRF trusted origins.
  • Добавить static/media storage и безопасную обработку файлов.
  • Настроить WSGI/ASGI-сервер, логирование и резервные копии.
  • Добавить тесты регистрации, входа, выхода и создания профиля.
